# 夜更かしループ（YOFUKASHI LOOP）

昔の個人ホームページ、ガラケーの待ち受け、電光掲示板のような「ちょっとレトロで可愛い」素材を自由に配置して、
ループするアニメーションを作るブラウザツールです。作った作品は GIF・動画（MP4 / WebM）・静止画（PNG）として書き出せます。

## 使い方

`index.html` をブラウザで開くだけで動きます（インストール不要）。GitHub Pages でもそのまま公開できます。

1. 左の「素材ライブラリ」から素材を選んでステージに追加（種類別・テーマ別の2通りで探せます）
2. ステージ上でドラッグして移動、ハンドルで拡大・回転（スマホは2本指でつまむ）
3. 「プロパティ（調整）」で色・文字・動きを変更
4. 「画面エフェクト」で仕上げ（グリッチ、VHS、色あせフィルム、雨など）
5. 「書出し」から GIF / 動画 / 静止画を保存

スマホでは素材を長押しするとゴミ箱が出て、ドラッグで削除できます。

## 収録している素材

- 回転する物体：ミラーボール、地球儀、3Dハート、CD、レコード、わっか惑星 など
- ドット文字：流れる・点滅・ウェーブ・タイプライター、ギャル文字変換つき
- ドット絵、HP・ガラケーのパーツ（キリ番看板、アクセスカウンター、相互リンクバナー など）
- 背景：ポップ柄、サイバー、夏休み、中華ネオン、大正ロマン、宇宙、純喫茶 など
- テーマ：ゆめかわ・ポップ／病み・退廃／サイバー／中華ネオン／大正ロマン／音楽／宇宙／純喫茶／HP・ガラケー／エモ・夕暮れ／夏休み／平成レトロ／ギャル・デコ

## メモ

- 作業内容はブラウザ（localStorage）に自動保存されます。「作品を保存」で JSON に書き出して、あとで「開く」で読み込めます。
- フォントは Google Fonts（DotGothic16 / Press Start 2P / Silkscreen / M PLUS Rounded 1c、いずれも SIL Open Font License）を読み込んでいます。
